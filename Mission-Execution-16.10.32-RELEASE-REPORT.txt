DEFECTS FOUND AND FIXED
1. Parameterized router declarations used string patterns such as /api/platform/admin/objective-runs/:runId. The shared router compared strings literally, so valid requests could return API route not found. Fixed centrally in src/worker/core/router.js. All existing string route declarations with :parameter segments now use exact segment matching, safely decoded parameters, and reject malformed encodings / encoded slashes. This repairs the underlying router instead of adding duplicate objective-specific routes.
2. Organization count disagreement came from different populations and a capped listing: the Control Plane derived the total from at most 100 listed rows, while the Command Center counted management profiles (including a different deletion-state scope). Both projections now count canonical active companies, and compliance data is joined only as an attribute. Failed count reads return unavailable/null instead of an inferred zero.
3. Objectives without a persisted run displayed an inert OPEN button. They now display a disabled NO RUN state.
