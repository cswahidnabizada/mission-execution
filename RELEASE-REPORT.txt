ON MISSION 16.10.48 — Production Route Adapter Foundation
Release type: Source candidate; production certification pending.
Base: ON MISSION 16.10.47 source candidate.

PURPOSE
Connect real application entry points to an explicit Layout Studio route-adapter boundary while preserving each canonical renderer and all existing business/mission behavior. The adapter marks the route context and refuses to apply drafts or any unverified release.

WHAT CHANGED
- Added a shared production-route adapter module with allowlisted route resolution for public homepage, registration, organization setup, mission workspace, executor workspace, and tenant workspace.
- Wired the adapter into the actual homepage, registration, and canonical application workspace entry points. It only adds route metadata and observes navigation; it does not replace page content, form handlers, authentication, tenant context, mission state, or action behavior.
- Added a strict activation boundary requiring an immutable VERIFIED release from the canonical release lifecycle and an explicitly certified route renderer. The current adapter intentionally refuses activation because route renderer parity is not yet certified.
- Updated Layout Studio route certification to distinguish installed adapters from certified production renderers.
- Updated Super Admin Layout Studio route panel metrics to show installed route adapters rather than mislabel them as connected renderers.
- Added 16.10.48 focused contract test and updated release identity/cache references.
- No database migration, production data change, deployment, or publication activation was performed.

VERIFICATION
- PASS: 16.10.48 production route adapter contract.
- PASS: complete configured `npm run check:release` under the available Node.js 22.16.0 runtime.
- PASS: JavaScript syntax checks for all modified route entry points and adapter module.
- BLOCKED: production build/CSS compilation because installed Node.js is 22.16.0 while project requires 24.18.0; the build environment gate stopped before CSS compilation.
- NOT TESTED: live browser route parity, accessibility, tenant-isolation runtime, active-release retrieval, publication, activation, rollback, or production deployment.

IMPORTANT BOUNDARY
This release installs adapters at actual route entry points; it does NOT claim that production layouts are now dynamically controlled by Layout Studio. Drafts remain draft-only. The current renderer binding count remains zero and publication remains disabled until canonical route-specific renderer integration and evidence are complete.
