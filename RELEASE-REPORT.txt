ON MISSION 16.60.0 — UNIFIED RESOURCE & ASSET CONTROL PLANE
Status: hardening candidate; not deployed
Base: 16.59.0

IMPLEMENTED
- Unified Resource workspace navigation for Inventory, Asset Studio, Overview, Dependencies, Lifecycle and Changes & Audit.
- Six-family inventory filtering remains based on the existing trusted asset type contracts; no shadow asset store or invented inventory rows.
- Asset 360 now exposes scope and operational readiness separately from lifecycle where returned by the owner.
- Dependency, lifecycle and audit context panels are populated only from canonical resource responses; missing evidence is explicitly reported as unavailable, not fabricated.
- Lifecycle actions continue through the existing canonical action adapter, with owner-side validation and read-back after non-purge actions.
- Data Studio no longer submits immutable code/role_code identity fields in edit payloads. The server merges canonical values from the owner record and enforces identity immutability.
- Product Definition resources bypass unsupported generic Data Studio inspection and route to Product Factory, their owning workspace.
- Release identity, package version, lockfile and manifest advanced to 16.60.0.
