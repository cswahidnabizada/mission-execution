ON MISSION 16.10.41 — Layout Studio Server-Owned Drafts
Release type: Source candidate; additive migration; publication remains blocked.
Baseline: 16.10.40 (user-reported deployed)

WHAT CHANGED
- Added migration 0160 with server-owned Layout Studio draft storage, revision snapshots, and draft audit events.
- Added guarded API routes for reading the canonical global experience draft, reading revision history, and saving drafts with optimistic revision checks.
- Draft writes require Super Admin step-up authorization. Reads require platform administrator authorization.
- Added server-side schema/size/component/property/responsive/governance validation; arbitrary HTML/JS/CSS remains disallowed.
- Stored draft revision snapshots include SHA-256 digests. Database triggers reject update/delete of historical draft snapshots.
- Connected Layout Studio to load the server draft, save a new revision, and view server-side version history. Browser local storage remains a fallback if the server draft authority is unavailable; it is not treated as server truth.
- Save responses explicitly state activeProductionChanged=false. Publishing remains disabled because canonical release adapter, immutable active release, post-publish verification and rollback are not integrated.
- No existing migration was changed; migration 0160 is additive. No production data was accessed or changed by this build.
