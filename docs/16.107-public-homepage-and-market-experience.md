# ON Mission 16.107.0 — Country-aware public homepage

## Product intent
The public homepage is the front door to one shared mission-execution platform. It explains the mission journey, data infrastructure, market model, platform capabilities and current public availability. Country selection changes the market experience without creating a separate product or authority.

## Country discovery
`GET /api/product/availability` remains the canonical public discovery authority. It now includes a safe `marketDiscovery` projection:
- Germany is represented using the existing Market Factory package and canonical public country-launch result. Market/release/onboarding state is displayed as returned; preparation is never represented as live onboarding.
- Afghanistan is represented from the existing `daftar_market_profiles` and country product launch state. Its six Daftar sector templates are discoverable, while tenant use remains gated by the canonical country product launch and existing organization/session eligibility.
- Other countries are included only when the canonical country product launch authority reports them as active.

## Afghanistan capability presentation
The homepage describes the implemented private ledger, inventory/Mojoodi, Qarz and settlement records, logistics entries, reference-only FX, batch passports/custody evidence, governed local units and encrypted offline capture. It explicitly distinguishes built capability from market activation. It does not open a new account system or bypass the existing Daftar tenant guard.

## Public market data
`GET /api/public/market-data?countryCode=AF&sectorCode=trade` is a read-only public projection over the existing replaceable `daftar_market_price_indices` snapshot. It returns only aggregate fields, only when:
- the country product launch is active;
- the matching Daftar profile is pilot/active and telemetry-enabled;
- each returned group meets the profile's minimum contributor cohort (never below five);
- the snapshot is fresh (20 minutes or less).

The route never reads or returns private Daftar entries, counterparty labels, private notes, company IDs, contributor keys or individual telemetry events. It states that values are opt-in merchant-reported indicators, not official statistics, financial advice, offers or proof of an individual transaction. Empty data is explicitly not represented as zero.

## Homepage experience
Responsive homepage navigation covers Mission Execution, Markets, Data Infrastructure, Public Data and Platform. The country cards switch the market situation panel; the public data controls query the read-only aggregate route. The existing public homepage route and Layout Studio route adapter remain in place. No second homepage route or backend is introduced.

## Release limits
This is a source candidate. It does not activate Afghanistan, publish telemetry, open registration, or certify live data. The actual public data feed remains empty until Afghanistan is activated, the Daftar market profile is enabled, verified organizations explicitly opt in, the HMAC secret is configured, and the cohort/freshness rules are met. Public browser, tenant isolation and production deployment acceptance remain required.
