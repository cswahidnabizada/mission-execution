# Human Work Model — Wave 5 Navigation Collapse

10.94.0 establishes the canonical authenticated navigation model for the Human Working Platform. Navigation now represents **human responsibilities**, not backend entities.

```text
TODAY     → What matters now?
WORK      → What can I work on now?
NETWORK   → Who and what is connected to work?
OBJECTS   → What operational objects matter?
PEOPLE    → Who is involved and what responsibility/access do they have?
ACCOUNT   → Who am I and what governs my account?
```

## Rules

- One canonical six-destination navigation model for the authenticated Operations Plane.
- Mission, Assignment, Execution, Attention, Focus, Requests, Executor and Company are capabilities/contexts, not competing top-level destinations.
- Context remains entered from Work and contextual surfaces; it is not a seventh destination.
- Product presentation can relabel canonical destinations but cannot remove them.
- Legacy hashes are compatibility aliases and resolve to canonical destinations until Wave 6.
- Control Plane remains a separate Admin Work Model.
- Navigation owns no truth, authorization or mutation authority.

## UX

Each destination communicates both where it goes and its human purpose. The same six destinations are available across authenticated roles; scoped data and authorization determine what each person can see or do.

## Wave 6 entry

After 10.94.0 is deployed and real-user tested, Wave 6 can retire obsolete human-facing screens, duplicate entry points and legacy routable implementations using the Wave 1 inventory and permanent release gates.
