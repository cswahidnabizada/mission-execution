# ON Mission 10.52.1 — Audit, Fixes & Remaining Certification

## Findings carried from the 10.52.0 audit

1. Product Publisher `renderWorkspace()` referenced `state` without receiving it.
2. Product Contract was hash-addressable but the exact canonical JSON snapshot was not persisted with the release.
3. Release lifecycle declared `VERIFIED` but publication verification jumped directly from `PUBLISHED` to `LIVE`.
4. Test Lab prepared a contract hash but verification did not enforce the prepared contract/dependency snapshot against the authorized release.
5. Publication and verification had multi-step consistency windows without a dedicated release-operation record/reconciliation path.
6. Product Publisher silently activated an inactive country during product start.
7. Product Publisher remained too monolithic and partially JSON-first.
8. `final-build.log` was stale and described 10.38.21 / migration 0091.
9. Clean-install CSS/build could not be proven in the supplied inspection environment because dependency installation timed out.
10. Release/runtime asset query strings and several historical release gates still pinned 10.52.0 and needed convergence to the current 10.52.x release.

## 10.52.1 fixes

- Publisher renderer now receives explicit render state.
- Added Publisher UI runtime regression gate.
- Product Contract uses stable canonical serialization.
- Authorized release stores immutable Product Contract JSON and SHA-256 hash.
- Authorized release stores a dependency snapshot hash.
- Release lifecycle now persists `PUBLISHED`, then `VERIFIED`, then `LIVE`.
- LIVE requires a verified release and an active launch.
- Prepared Test Lab scenarios store contract/dependency hashes.
- Verification rejects stale scenario contract, dependency, launch or release state.
- Publisher verification uses the canonical Publisher verification orchestrator and advances the release lifecycle.
- Added explicit Product Release Operation states: PRECHECK, PREPARING, PUBLISHING, VERIFYING, COMMITTED, FAILED, RECONCILIATION_REQUIRED.
- Added deterministic reconciliation when launch activation committed before lifecycle acknowledgement.
- Product Publisher no longer silently activates an inactive country.
- Product definition and lifecycle JSON editors were moved behind Advanced sections; the primary UI is semantic with component/state/transition summaries.
- Updated all runtime asset version query strings to 10.52.1.
- Updated historical release gates so they validate the current 10.52.x release instead of falsely pinning 10.52.0.
- Replaced stale `final-build.log` with truthful 10.52.1 evidence; no false build PASS is recorded.
