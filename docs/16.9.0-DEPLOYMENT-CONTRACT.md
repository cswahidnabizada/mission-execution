# ON Mission — Production Deployment Contract

## Canonical release identity
- The single canonical current-version source is `/VERSION`.
- Current product release: read `/VERSION` at release time; the contract is not pinned to a historical release.
- Production is the only deployment environment configured in this repository.

## Canonical toolchain
- Node.js: 24.x (the production build gate validates the supported major version).
- npm: 10.x or 11.x, according to the repository build gate.
- `.npmrc` enables `engine-strict=true`; mismatched Node versions fail closed.

## Canonical production command
```bash
npm run deploy
```

The package entry point delegates to the governed underlying command `npm run deploy:production`; use `npm run deploy` in Cloudflare Workers Builds so the canonical entry point is consistent across environments.

Expected sequence: build preflight → deterministic release generation → CSS build → complete release checks → required runtime and recovery certification → remote D1 migrations → Wrangler deploy. Failure at any stage must stop subsequent stages.

Cloudflare Workers Builds must use `npm run deploy` as the deploy command. Do not configure `npx wrangler deploy` as the routine release path: it bypasses the repository build, release, runtime/recovery certification, and migration-order gates. A successful raw Wrangler upload is deployment evidence only; it is not evidence that the omitted gates passed.

## Post-deploy evidence
1. Capture the Cloudflare build/deploy log showing the canonical command and toolchain.
2. Verify remote D1 migration state without resetting or recreating the production database.
3. Verify the deployed release identity matches the package `/VERSION` through the platform's existing runtime health/version surface.
4. Test product/market publication, authorization boundaries, and recovery with authorized identities.
5. Execute controlled mission certification through OBSERVE → UNDERSTAND → PLAN → EVALUATE → ACCEPT → AUTHORIZE → PREPARE → ASSIGN → EXECUTE → EFFECT → VERIFY → RECOVER → OUTCOME → LEARN → NEXT SITUATION → OBSERVE.
