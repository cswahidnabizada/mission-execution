- The single canonical current-version source is `/VERSION`.

- Production is the only deployment environment configured in this repository.

## Canonical toolchain
- Node.js: 24.x (the production build gate validates the supported major version).
- npm: 10.x or 11.x, according to the repository build gate.

## Canonical production command
```bash
npm run deploy:production
```

Expected sequence: build preflight → deterministic release generation → CSS build → complete release checks → required runtime and recovery certification → remote D1 migrations → Wrangler deploy. Failure at any stage must stop subsequent stages.

Do not use `npx wrangler deploy` as the routine release path because it bypasses the repository's release and certification gates.
