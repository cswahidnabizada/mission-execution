# ON Mission 13.7.0 — Governed Mission Planning

## Purpose

13.7 makes PLAN a canonical governed capability while preserving the existing Mission Truth, Assignment, Authorization, Execution, Verification, Recovery, Outcome and Continuity authorities.

## Journey

OBSERVE → UNDERSTAND → PLAN → POLICY CHECK → AUTHORIZE → PREPARE → ASSIGN → EXECUTE → VERIFY → RECOVER → OUTCOME → LEARN → NEXT SITUATION

## Planning boundary

The Mission Planning Authority persists a structured plan proposal. It does not mutate mission truth, authorize actions, assign executors, create execution intents, or execute actions.

## Plan inputs

- canonical mission truth
- current situation
- readiness and canonical action decisions
- mission objective
- sector contract
- assignment context
- capability/resource contracts
- policy/autonomy signals
- verified outcomes and recovery history already exposed by the existing advisory planner

## Plan outputs

- objective
- situation
- alignment
- ordered candidate steps
- recommended action
- alternative actions
- constraints
- risk
- confidence
- assignment requirement
- required resources/capability contract context
- recovery strategy
- canonical context hash
- deterministic plan hash

## Persistence

`mission_plans` is tenant scoped and mission scoped. Plan keys are deterministic. Proposed plans supersede previous proposals for the same mission. Acceptance is explicit and does not authorize execution.

## Safety invariants

1. Planning is non-executing.
2. A plan is not authorization.
3. A plan is not assignment.
4. A plan is not execution intent.
5. Current canonical truth must be revalidated before authorization.
6. Unknown or insufficient evidence cannot authorize a plan.
7. Planning cannot become mission truth.
8. Only one canonical Planning authority persists plan proposals.
9. Existing advisory planner signals remain advisory; the new authority persists and governs them instead of duplicating their algorithm.
10. Recovery strategy for stale or divergent plans is re-plan and re-authorize.
