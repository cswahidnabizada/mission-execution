# 16.10.47 — Production Route Certification Bridge

This release adds a governed worklist for connecting Layout Studio to actual production routes. It deliberately distinguishes a source-mapped route from a renderer binding and a certified runtime route.

A route may only become editable/publishable after its canonical renderer adapter, responsive browser parity, accessibility, authorization/tenant-isolation behavior, and recovery evidence have been tested. Until then, the route remains inspect-only and publication remains disabled.

The read-only endpoint is `/api/platform/admin/layout-studio/certification`. It is administrator-protected and reports route mapping, renderer status, parity status, required evidence, and blockers. It is not a certification attestation.
