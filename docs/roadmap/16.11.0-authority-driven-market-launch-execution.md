# 16.11.0 — Authority-Driven Market Launch Execution

## Objective
Resolve should offer meaningful, task-specific controls and invoke owning authorities rather than asking users to fill generic evidence fields that have no operational effect.

## Delivered in this candidate
- Honest evidence-submission semantics for stage-contract steps.
- Backend rejects evidence-only completion claims.
- Removed manual COMPLETE option from generic task status selectors.
- More meaningful evidence field labels.
- Added focused regression test.

## Still required
- Build a registered command adapter for each permitted command.
- Connect product/resource search, create, configure and explicit market-link operations to their owning APIs.
- Connect legal review, certification, release and recovery operations to their respective authorities.
- Require read-after-write canonical verification for each adapter.
- Make fields schema-driven by command and task, hiding unused fields.
- Full release suite, Node 24 build, authenticated browser tests and deployed certification.
