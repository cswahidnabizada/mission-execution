# 16.10.99 — Stage Contract UI/API Integration

## Goal
Connect the Resolve workspace to the canonical server-defined Stage Contract Engine and ensure parent-task completion is governed by persisted server state rather than browser-supplied contract JSON.

## Implemented
- Resolve fetches the stage contract for the selected task through the authenticated read endpoint.
- Ordered steps render canonical status, authority, permitted command, prerequisites, evidence requirements and recovery guidance.
- Each step posts evidence/status through the step-up-protected substep endpoint.
- Successful updates re-read the canonical contract and re-render persisted state in Resolve.
- Contract read/update failures leave the task open and provide retry guidance.
- Parent task completion checks persisted stage-contract state; missing initialization or incomplete required steps blocks completion.
- Legacy release compatibility allowlists were extended to include 16.10.99 where needed; historical checks remain enabled.
- No database migration was added; migration high-water mark 0163 and schema hash are preserved.
