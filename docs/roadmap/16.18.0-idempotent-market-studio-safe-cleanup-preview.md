# ON Mission 16.18.0 — Idempotent Market Studio and Safe Cleanup Preview

## Purpose
Prevent duplicate market versions and make cleanup understandable and lifecycle-aware without weakening canonical authority boundaries.

## Delivered in this candidate
- Deterministic recursive JSON canonicalization before package source hashing.
- Existing database unique constraints remain authoritative for package identity, product/country identity, version identity and source hash.
- Authenticated read-only cleanup preview returns records planned for deletion, retained shared records, and protection reasons.
- UI requires preview, then step-up, then typed confirmation.
- Delete service recomputes eligibility before mutation; a stale preview cannot authorize deletion.
- No migration; migration high-water mark 0163 is preserved.
