# ON Mission 10.97.0 — Human Platform Configuration Studio

10.97.0 turns the 10.96 Human Platform Control Center foundation into a governed Configuration Studio and refreshes the Super Admin Control Plane shell into one coherent control-plane experience.

## Studio scope

- Human Platform configuration studio
- Canonical six-destination navigation editing
- Work composition governance
- Context governance
- Role experience visibility inspection
- Attention presentation policy
- Read-only impact preview through the existing configuration authority
- Governed draft → validate → authorize → active lifecycle
- Rollback through a new governed draft

## Permanent authority boundary

Super Admin configures presentation and policy. It does not own Mission truth, Assignment truth, lifecycle truth, evidence validity, tenant data or direct domain mutation. Experience visibility never grants authorization. Mutations remain behind the canonical Action Registry.

## Control Plane visual convergence

10.97 replaces the older admin-era visual hierarchy with a consistent control-plane shell:

- lighter workspace canvas
- clearer dark navigation rail
- compact grouped navigation
- focused workspace stage
- reduced redundant chrome
- responsive mobile behavior
- shared Studio visual language

The redesign is presentation-only and does not create a new administrative authority.

## No new domain authority

Human Platform configuration continues to use the canonical `platform_configuration_versions` authority:

- domain: `rendering`
- key: `human-work-platform`
- contract: `human-work-platform.v1`

No D1 migration is introduced. Migration high-water remains 0124.
