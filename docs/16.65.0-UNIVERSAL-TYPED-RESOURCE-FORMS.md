# 16.65.0 — Universal Typed Resource Forms

## Contract
Data Studio now renders editable fields from the canonical resource definition's `fieldSchemas`. It supports string, text, integer, number, boolean, enum, JSON and relationship-reference field types. Constraints are presentation and early-validation hints; the canonical owning service remains authoritative at preview and commit.

## Safety
- Identity and scope are not made editable.
- The form emits sparse changes only.
- Numeric, boolean and JSON values are normalized before preview.
- Relationship references are not treated as authorized relationship edges. The 16.66.0 engine must resolve canonical targets, validate type and scope, and persist through the owning relationship authority.
- No save is considered complete without the existing server-side read-after-write verification.

## Operator validation
Run the release checks and a Node 24 build. Then test each resource family in an authenticated environment, including create, edit, preview, validation, commit, refresh and recovery. Do not infer live correctness from static source tests.
